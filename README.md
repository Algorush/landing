# Alexander Goryushkin — Portfolio

A lightweight, responsive, bilingual (English / Spanish) static portfolio website.

## Preview locally
Open `index.html` in a browser. No build step is required.

## Publish on Vercel
1. Create a new GitHub repository and upload the contents of this folder.
2. Sign in at https://vercel.com/ and choose **Add New → Project**.
3. Import the repository.
4. Keep the Framework Preset as **Other**. Leave Build Command and Output Directory empty.
5. Deploy.

Vercel will provide a `*.vercel.app` address.

## Before publishing
- Replace the generic GitHub, LinkedIn and Upwork profile links in `index.html` with your exact profile URLs.
- Add links/screenshots for projects you are allowed to show.
- Check that the service descriptions accurately represent your current offer.
